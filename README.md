# QuickFeast Homepage MVP

Create the first QuickFeast homepage MVP. QuickFeast is a modern food-delivery website.

Design system:
- Cream/off-white page background
- Tomato red for primary buttons and important accents
- Warm yellow for highlights/promotional accents
- Dark charcoal for text
- Vibrant food photography that pops against the warm palette
- Modern, appetizing, friendly and premium-but-approachable
- Rounded cards/buttons, strong typography, generous spacing, subtle shadows, tasteful micro-interactions
- Fully responsive desktop/tablet/mobile

Homepage:
1. Sticky navbar with QuickFeast logo, simple links, and Login / Sign Up buttons.
2. Hero visible immediately on page load. Headline exactly: "Better food for most people". Supporting line: "Get your choice of food fast and hot." Add a prominent tomato-red "Order Now" CTA and a secondary action. Include attractive food photography.
3. Food search/discovery area.
4. Popular food categories with images.
5. Featured/popular restaurant cards using realistic mock data: restaurant name, food image, rating, cuisine, delivery time, price indicator.
6. Warm-yellow promotional section.
7. "Why QuickFeast?" section with fast delivery, fresh food, easy ordering, trusted restaurants.
8. Footer.

Login behavior:
- Keep everything on the same homepage for this MVP.
- Add a polished login/sign-in section lower down the page so it appears naturally as the user scrolls.
- Navbar Login should smoothly scroll to that section.
- Login UI can be mock/no backend yet.

Do NOT build restaurant detail pages, cart, checkout, admin dashboard, database, payments, or backend yet. Use reusable components, semantic accessible HTML, responsive layouts, working image URLs/placeholders, and avoid broken links. The result should look like a real food-delivery landing page, not a generic SaaS template.
