# QuickFeast homepage MVP

## Build
- Establish a warm cream, tomato-red, yellow, and charcoal design system with strong responsive typography and subtle motion.
- Replace the placeholder with one polished scrolling homepage: sticky navigation, food-led hero, search, categories, restaurant cards, promotion, benefits, login, and footer.
- Use the generated food photography throughout and make all calls-to-action work within the page, including smooth scrolling to ordering and login areas.
- Keep sign-in as a polished mock form with clear feedback and no backend.

## Quality
- Use semantic, accessible structure and labeled controls.
- Optimize layouts for desktop, tablet, and mobile.
- Add unique QuickFeast page metadata and a matching favicon.
- Verify the app compiles and inspect the live page at desktop and mobile sizes.

## Technical details
- Keep the MVP on the existing `/` route and organize repeated content into reusable React components.
- Define colors, fonts, shadows, and transitions as semantic tokens in the global design system.
- Use bundled image assets rather than external image links, avoiding broken media.
